# Gravitational Lens Einstein Ring Canvas

## 概要
シュワルツシルト偏向角公式を用いた重力レンズシミュレーター。背景銀河の変形とアインシュタインリング形成をレイトレーシングでリアルタイム描画。

## 機能
- シュワルツシルト点質量レンズのフルレイトレーシング（全ピクセル逆追跡）
- アインシュタイン半径スライダー（質量に対応）
- 光源位置 X/Y スライダーによる像の変化観察
- 光源形状: 点光源・円盤銀河・渦巻き銀河
- 光源の自動移動アニメーション（コースティック通過→像の分裂/合体）
- 臨界曲線（アインシュタイン円）・コースティック表示
- 像ラベル表示（A, B）
- 倍率 μ・像の数のリアルタイム計算
- キャンバスクリックで光源位置を直接指定

## 使い方
1. 「光源を自動移動」ボタンで銀河がアインシュタインリングを形成する様子を観察
2. スライダーで手動操作: 光源が軸上（X=0, Y=0）でリング、外れると2像に分裂
3. アインシュタイン半径スライダーでレンズ質量を変更
4. キャンバスをクリックして任意の位置に光源を配置
